Rahee - Crowd Simulation Engine

Simulates crowd movement to estimate congestion and stampede risk.
Lightweight command-line tool that loads a venue YAML and outputs basic metrics.
Designed for quick pre-event checks and simple exports.

Run
----
Install dependencies:

```bash
pip install -r requirements.txt
```

Run a simulation (example):

```bash
python -m crowd_simulation path/to/venue.yaml --output results.json
```

That's it — minimal usage for quick checks.
